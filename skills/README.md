# Skills runtime của TaskMate

Mỗi Skill là một thư mục con có `SKILL.md` (mô tả khi nào dùng + hướng dẫn), có thể kèm template và ví dụ.
Agent đọc phần mô tả ngắn của mọi Skill, chọn Skill phù hợp rồi mới nạp nội dung đầy đủ (design mục 4.2).

Dự kiến: `task-writing/`, `bug-report/`, `story-breakdown/`, `scrum-conventions/`, `missing-info/`, `sprint-report/`.
